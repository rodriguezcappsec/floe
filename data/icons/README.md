# Floe application icon

`hicolor/512x512/apps/io.github.rodriguezcappsec.Floe.png` is a deterministic
512 by 512 derivative of the repository's owner-authorized `icon_floe.png`
project asset. It is the application icon embedded in Floe and installed by
the Linux package.
