# Phosphor icon subset

The 44 SVG files under `scalable/actions/` are an unmodified subset of Phosphor
Icons Core 2.1.1 Regular, pinned to commit
`2b75f3ad12b420c9504ef05df8d2564a28f8500e`.

They are bundled locally: Floe performs no icon download at runtime. The files
retain `currentColor` and the `-symbolic` suffix so GTK can apply semantic
foreground colors. See `THIRD_PARTY_LICENSES/Phosphor-Icons.txt` for the MIT
license and source attribution.
